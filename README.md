## 👨‍💻 About Me

I'm a Computer Science undergraduate focused on **Agentic AI Engineering, Generative AI, and Full-Stack Development**. I build systems where specialized agents plan, use tools, validate results, recover from failures, and escalate sensitive actions to humans when needed.

- 🤖 Built **four multi-agent systems** for enterprise operations, software engineering, customer support, and deep research.
- 🧠 Interested in **LLM orchestration, agentic workflows, RAG, tool calling, and evaluation**.
- 🛡️ Focus on reliable agents with **human-in-the-loop approvals, least-privilege tools, sandboxing, and audit trails**.
- 🌐 Build end-to-end products with **FastAPI, Python, Next.js, React, and databases**.
- 🧩 Solved **150+ DSA problems** across LeetCode and CodeChef.
- 🎯 Seeking opportunities in **Agentic AI / LLM Engineering**.
